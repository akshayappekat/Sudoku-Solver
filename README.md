# Sudoku Solver 🧩

A Python-based application that solves Sudoku puzzles using a backtracking algorithm. This project demonstrates both the algorithmic logic required to solve constraint-satisfaction problems and a simple interactive interface to visualize the solution process.

## Features

- **Automatic Sudoku Solver**: Solves any valid 9x9 Sudoku puzzle instantly.
- **Graphical User Interface (GUI)** *(if included)*: Interactive grid to enter puzzles and visualize solutions.
- **Backtracking Algorithm**: Efficient recursive method to explore and solve the puzzle space.
- **Input Validation**: Ensures only valid numbers and puzzles are processed.

## Technologies Used

- **Python**
- **Libraries**: 
  - `Pygame` *(if GUI included)*  
  - `Tkinter` *(if GUI included)*  
  - Standard Python (for algorithm and console version)

## Project Structure

- Python scripts implementing the Sudoku solver logic
- Optional GUI files for interactive input and display
- Sample puzzles for testing and demonstration

## Purpose

This project showcases:
- **Algorithm design and problem-solving** using recursion and backtracking
- **Python programming proficiency**
- **Optional GUI development** for better user experience

## How it works

1. The program accepts an unsolved 9x9 Sudoku puzzle (via console or GUI).
2. It applies the backtracking algorithm to fill in valid numbers.
3. The completed solution is displayed or printed once solved.
